# 💻 DevTinder

> Connect. Collaborate. Build Together.

DevTinder is a full-stack developer networking platform inspired by Tinder, where developers can discover like-minded programmers, send connection requests, build their professional network, and collaborate on exciting projects.

---

## ✨ Features

### 🔐 Authentication
- Secure User Signup & Login
- JWT Authentication
- Password Encryption using bcrypt
- Protected Routes

### 👤 User Profile
- Create and Update Profile
- Upload Profile Picture
- Skills & Bio
- GitHub Profile Link
- Experience & Interests

### 🤝 Connection System
- Send Connection Requests
- Accept or Reject Requests
- View Pending Requests
- View Connected Developers

### 🔍 Developer Discovery
- Browse Developers
- Smart Feed
- Excludes Already Connected Users
- Clean & Responsive UI

### 🛡 Security
- Password Hashing
- JWT Authentication
- Input Validation
- Secure Cookies
- Protected APIs

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/YASHdroidgmail/DevTinder.git
```

Move into the project

```bash
cd DevTinder
```

---

## Install Dependencies

### Backend

```bash
cd server
npm install
```

### Frontend

```bash
cd client
npm install
```

---

## Environment Variables

Create a `.env` file inside the **server** folder.

```env
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key

CLIENT_URL=http://localhost:5173
```

---

## Run Backend

```bash
npm run dev
```

---

## Run Frontend

```bash
npm run dev
```
